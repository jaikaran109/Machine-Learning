# 🚀 Phase 0: Python Foundations for Machine Learning

## 📌 Overview

Before diving into Machine Learning, it is essential to build a strong foundation in Python.

This phase focuses on learning the core Python concepts required for Data Science, Machine Learning, and Artificial Intelligence. The goal is not just to learn syntax, but to understand how Python is used to solve real-world problems and process data efficiently.

By the end of this phase, you will be comfortable writing Python programs, working with data structures, handling files, organizing code, and understanding Object-Oriented Programming.

---

# 🎯 Goals

* Learn Python fundamentals from scratch.
* Develop problem-solving skills using Python.
* Understand commonly used data structures.
* Learn how to organize code using functions and modules.
* Build a strong base for NumPy, Pandas, and Machine Learning.
* Write clean, readable, and reusable code.

# 🧠 Importance for Machine Learning

Every Machine Learning project relies heavily on Python fundamentals.

Examples:

### Data Processing

```python
data = [10, 20, 30]
```

Uses Lists.

---

### Feature Storage

```python
student = {
    "age": 20,
    "cgpa": 8.5
}
```

Uses Dictionaries.

---

### Data Cleaning

```python
unique_values = set(data)
```

Uses Sets.

---

### Reusable Logic

```python
def normalize(x):
    return x / 100
```

Uses Functions.

---

### Reading Datasets

```python
with open("data.csv", "r") as file:
    data = file.read()
```

Uses File Handling.

---

Without Phase 0, understanding libraries such as NumPy, Pandas, Scikit-Learn, TensorFlow, and PyTorch becomes much harder.
