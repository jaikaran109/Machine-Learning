## Topics

| Topic | What it does |
|---|---|
| **SELECT** | Chooses which columns to return |
| **WHERE** | Filters rows by a condition |
| **ORDER BY** | Sorts the results |
| **GROUP BY** | Groups rows to compute summaries such as counts and averages |
| **HAVING** | Filters groups after aggregation |
| **JOINs** | Combines rows from related tables |
| **Subqueries** | A query inside another query |
| **Window Functions** | Calculations across related rows, such as running totals and rankings |

## Where SQL is used

- Pulling training data for ML projects
- Aggregating customer and sales data
- Preparing datasets before loading them into Pandas

By the end of this phase, you can:
